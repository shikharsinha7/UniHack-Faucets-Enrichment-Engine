# Hackathon notes

UniHack (Unilog x Hack2Skill), August 2026.

- **Scope.** The challenge's guide recommends depth over breadth and names faucets as a good single category for a demo, so this build covers one category end to end instead of all 1,000 sample rows or all 252 output columns.
- **Missing reference files.** Only the guide, the sample input and one worked example were distributed. The content guidelines, the faucet list of values, the units standard and the manufacturer master list were not, so the project uses hand-curated stand-ins (see the README).
- **Steps chosen.** The guide asks teams to pick two or three steps of the pipeline. This build does classification and normalisation, vocabulary-constrained attribute extraction, and description assembly.
- **Outcome.** The build was not submitted: the laptop it was being built on failed shortly before the deadline.
